# Brand assets

- `inkexplain-mark.svg`, `inkexplain-hero.svg`, `stickman-pose-sheet.svg`: hand-coded vector art, original to InkExplain. Not model output. The older hero scene is no longer used in the English README.
- `readme-hero-desktop-light.png`, `readme-hero-desktop-dark.png`, `readme-hero-mobile-light.png`, `readme-hero-mobile-dark.png`: a layout, not an illustration. They place the four real renders in `assets/examples/` (see its README for tool, date, hash, and review status) beside original typography, unmodified apart from scaling. Source: `hero-source/readme-hero.html`; open it at 1600 x 1130 (add `?dark` for the dark variant, `?mobile` at 760 x 2150 for the stacked one). `hero-source/thumb.html?<name>` makes the 640 x 360 thumbnails.
