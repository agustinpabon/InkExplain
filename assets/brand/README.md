# Brand assets

- `inkexplain-mark.svg`, `inkexplain-hero.svg`, `stickman-pose-sheet.svg`: hand-coded vector art, original to InkExplain. Not model output. The older hero scene is no longer used in the English README.
- `readme-hero-light.png`, `readme-hero-dark.png`: a layout, not an illustration. They place the two real renders in `assets/examples/` (see its README for tool, date, and hash) beside original typography. The renders are unmodified apart from scaling. Source: `hero-source/readme-hero.html`; open it, or add `?dark` to its address, in a browser at 1600 x 760 to reproduce them.
