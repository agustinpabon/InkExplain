# CLAUDE.md

Instructions for Claude Code working in this repository live in [AGENTS.md](AGENTS.md); read it first.

Using the skill itself from Claude Code: copy `skills/inkexplain/` to `~/.claude/skills/inkexplain/` (all projects) or `.claude/skills/inkexplain/` (one project). Claude Code has no built-in image generator, so InkExplain runs in prompt mode unless an image-generation tool is connected, for example through an MCP server.
