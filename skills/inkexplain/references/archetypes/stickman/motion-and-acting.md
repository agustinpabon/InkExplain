# Stickman Motion and Acting

How Stickman moves, and how the shared structure types from `references/workflow/composition-grid.md` look with it. Each image takes one structure type, one idea, and one physical action done with the whole body.

## Actions

Carry, pull, push, point, weigh, sort, bridge, hold back, stack, turn a crank; also lift, hand over, fit, untangle, climb, guard, measure, sweep, plant, unpack, and walk a path.

Choose the verb that is the idea. "Trust is built step by step" becomes Stickman laying planks across a gap; "too many requests" becomes Stickman holding back an overflowing funnel with both arms.

### Pose vocabulary

Every pose keeps the identity contract: asymmetrical, the spine leaning into the work, one soft bend per limb, each arm ending on the object. `pose-sheet.png` shows the first eight.

| Pose | Body language | Use it for |
|---|---|---|
| Carry | spine leans back under the load, both arms bent beneath the object, knees soft | workflows, handoffs, ownership, load |
| Pull | spine leans away from the object, arms extended along the rope or lever, back foot braced | effort, dependencies, cause and effect |
| Push | spine leans into the object, arms straight against it, rear leg driving; the same pose presses a stamp or a button home | momentum, resistance, releases, renewing or approving something |
| Point | one arm in a straight line at the key object, the other relaxed, head turned along the arm | explaining, locating a breakpoint |
| Weigh | one arm out holding a balance, head tilted toward the heavier side | trade-offs, comparisons |
| Sort | one arm reaching to a pile, the other placing a card in a slot, head turned between them | classification, filtering, routing |
| Bridge | body stretched toward the far side, arms laying a plank across the gap | integration, trust, handoff gaps |
| Hold back | feet planted wide, arms spread against the pressure, brows focused | bottlenecks, rate limits, protection |
| Stack | on tiptoe, arms up, setting the last block on a tower | layers, abstractions, building |
| Turn a crank | one arm cranking, the other braced, torso twisting | loops, iteration, automation |
| Walk | one leg forward, the opposite arm forward, tilt toward the path | sequences, routes, journeys |
| Shrug | elbows in, forearms out and up, head tilted, brows raised | uncertainty, ambiguity, "it depends" |
| Untangle | both arms working a knot, head bowed | complexity, refactoring |

### Expressions

Only the brows, the head tilt, and the body change. The dot eyes never do, and the face never gets a mouth.

| Expression | Brows | Head | Use it for |
|---|---|---|---|
| Calm | none | level | explaining, neutral steps |
| Focused | angled in and down | level or forward | effort, precision |
| Puzzled | one raised, one flat | tilted | doubt, comparison, bugs |
| Startled | both high | tilted back | failure, surprise, breakpoints |
| Pleased | both soft arches | slightly back | the fix working, a result |

### Timing

- A single image shows the decisive moment: the plank touching the far bank, the last block landing, the lever at its limit. Not the setup, not the aftermath.
- Mini comics use two to four beats (setup, action, result), one action per beat, with Stickman at the same size, weight, and face in every panel. Only the pose, expression, and props change.

## Patterns

- **Workflow**: material enters on the left as loose scribbles, passes through one hand-built machine that Stickman works, and leaves on the right as a few clean shapes.
- **System close-up**: draw only the decisive part, large, with Stickman working at it; suggest the rest of the system with two or three faint outlines.
- **Before and after**: a tangle on the left, the same material in order on the right, and Stickman making the change in the middle.
- **State change**: two small Stickman figures, the same Stickman in a different pose and expression in each, one short label each; the state that matters gets the vermilion accent. For three or four states, plan a mini comic instead.
- **Comparison**: two figures only, both the same Stickman, each handling one option with the same effort and line weight, so the difference reads as content.
- **Concept metaphor**: one large, slightly absurd object, such as a scale weighing two clouds or a funnel the size of a room, worked by Stickman.
- **Layers**: a hand-drawn stack with slightly uneven layers; Stickman props up, inspects, or adds one.
- **Route map**: one wandering path with three to five stops; Stickman walks it or carries something along it.
- **Mini comic**: two to four loose panels separated by whitespace instead of frames, one action per panel.

## Supporting objects

Everyday, low-tech things with obvious physical behavior: ropes, planks, levers, cranks, scales, boxes, crates, ladders, funnels, pipes, valves, gates, doors, keys, locks, stamps, signposts, stepping stones, buckets, nets, and clotheslines.

Use one to three per image, and prefer objects that fill, leak, balance, jam, open, or connect. Draw them in the same marker, lighter than the figure.

## Originality

- Invent a new metaphor for each source; do not reuse a scene from an earlier image.
- Two images in one series never share both the pose and the main object. Vary the pose before deforming the figure.
- When an idea repeats across articles, keep the idea and change the object and the action.
- Never trace a pose from a reference image, including `pose-sheet.png`; draw a new pose for each scene.
