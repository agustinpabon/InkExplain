# Go Gopher Rights

## Source

- Archetype: Go Gopher (`gopher`), category `mascot`, status `active`. Not the default archetype: only its aliases in `registry.json` (listed in `references/routing.md`) select it. Generic terms such as `go`, `blue mascot`, `animal`, and `logo` never select it.
- Character: the Go gopher, designed by Renee French.
- Rights holders: Renee French (design); Takuya Ueda (bundled drawing).
- Official source: the Go blog, https://go.dev/blog/gopher.
- License: Creative Commons Attribution 4.0 (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/). That page says the gopher images are Creative Commons Attribution 4.0 licensed and that you must give credit to their creator, Renee French, wherever they are used.
- Bundled reference: `references/archetypes/gopher/gopher.png`, a front-facing vector drawing of the gopher by Takuya Ueda. It is an unmodified copy of `gopher.png` in https://github.com/golang-samples/gopher-vector at commit `9fe99fbf17b019125bf649f8a921882b54e151a6`: git blob SHA-1 `26b98931ab6f42d5892f22cba85f93b90ad9fc4c`, SHA-256 `252b6e8feb893f5636865f27c6561664de66f89350ad26b5e3ff3775e12aca33`, 114063 bytes, 1634 x 2224 pixels. That repository's README says the Go gopher was designed by Renee French and that `gopher.{ai,svg,png}` was created by Takuya Ueda and is licensed under the Creative Commons 3.0 Attributions license; it has no separate license file. That is Creative Commons Attribution 3.0 (CC BY 3.0, https://creativecommons.org/licenses/by/3.0/); the README gives no link and names no jurisdiction, so the generic license is the one recorded here. The file is the identity authority for the marker set in `identity.md`.
- Earlier file: a previous version of this pack bundled a different `gopher.png`, a resized and recolored copy of the same drawing with a thicker outline and a white border added, from Visual IP Illustrations, with no recorded author. It was replaced by the original drawing so the bundled file can be checked against its source. `docs/provenance.md` in the repository has the measurements.
- Attaching `gopher.png` to an image request is optional, because `identity.md` lists every marker.

## Rights and restrictions

- Credit line: "The Go gopher was designed by Renee French (https://go.dev/blog/gopher) and is licensed under Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/)."
- Credit Renee French whenever generated images are published.
- When `gopher.png` was attached as a reference, credit Takuya Ueda as well: "The reference drawing is by Takuya Ueda (https://github.com/golang-samples/gopher-vector) and is licensed under Creative Commons Attribution 3.0 (https://creativecommons.org/licenses/by/3.0/)." That license asks for the creator's name, the license (its text or its link, with every copy of the drawing), and a link to the work, and for an adaptation a credit that says the work was used; an image made with the drawing as its reference is an adaptation of it.
- Keep this record with `gopher.png` whenever the pack is redistributed.
- No Go logo. The logo is not part of this archetype's identity and never appears in its images, prompts, or labels.
- No claims of official Go project affiliation, approval, sponsorship, or endorsement, in images, labels, prompts, or delivery reports.
- Status changes are a maintainer decision recorded in `registry.json`.
